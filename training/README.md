# Training Module

This directory contains all training scripts for different classifiers.

## Files

- `train_image_classifier.py` - Main image classifier training script
- `train_letter_classifier.py` - Handwritten letter classifier training script
- `model_integration.py` - Integration module for combining different classifiers

## Usage

Run training scripts using:
```bash
python train_image_classifier.py
python train_letter_classifier.py
```
